# Obsidian Web Clipper

Browser extension for Obsidian that captures web articles and converts them to Markdown notes.

## Role/Context

The Web Clipper is the fastest way to get sources into your raw collection. It:
- Captures full web articles as Markdown
- Downloads images locally (optional)
- Adds metadata (URL, title, date)
- Creates a new note in your vault

## Key Attributes

- **Type:** Browser extension (Chrome, Firefox, Safari, Edge)
- **Output:** Markdown files
- **Images:** Can download locally or keep remote URLs
- **Metadata:** Auto-captures URL, publication date, author

## Workflow

1. Click clipper button on any web page
2. Review captured content in Obsidian
3. Organize into appropriate folder
4. Use Ctrl+Shift+D to download remote images locally
5. Image URLs auto-rewrite to local paths
