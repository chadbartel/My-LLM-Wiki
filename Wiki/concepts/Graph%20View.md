# Graph View

An interactive visual representation of all notes in a vault as nodes and their links as edges.

## Definition

Graph view renders your entire vault as a network:
- **Nodes** = Individual notes
- **Edges** = Wikilinks between notes
- **Interactive** = You can zoom, pan, click nodes to navigate

## What It Reveals

- **Hubs** — Notes with many connections (often central concepts or highly cited sources)
- **Clusters** — Groups of related notes (topic areas with internal connections)
- **Orphans** — Isolated notes with no links (candidates for deletion or connection)
- **Bridges** — Notes connecting different clusters (important synthesizing notes)
- **Emergence** — Patterns and relationships you didn't consciously build

## Why It Matters

- **Pattern Recognition** — Humans are visual. Seeing the graph reveals structure that text alone doesn't
- **Health Check** — Orphans and sparse clusters indicate maintenance opportunities
- **Navigation** — Faster than search for exploring related topics
- **Serendipity** — Unexpected connections inspire new ideas

## Example: Well-Formed Graph

```
      [Core Concept] ← Hub with 12 connections
      /    |    \
    /      |      \
[Concept A] [Concept B] [Concept C]
  |         |              |
[Source 1] [Source 2]   [Source 3]
  |         |              |
[Entity X] [Entity Y]   [Entity Z]
```

The hub (Core Concept) connects to multiple domain areas. Each domain has sources and entities.
